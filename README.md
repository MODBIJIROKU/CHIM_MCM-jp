# CHIM(AIagent) MCM 翻訳ファイル

CHIM(AIagent) MCM 日本語化ファイルを配布させて頂いています
非公式の翻訳パッチです

## 使い方

AIAgentMCMConfigScript_pex_english_japanese.xml は xTranslator 用です
xTranslator を使用して、CHIM(AIagent) 英語版 AIAgentMCMConfigScript.pex に適用してください
